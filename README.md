# dsh-web-omni

把 **DeepSeek Web** 接进 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（DSH）的插件。

**装完即用**：装好后模型选择器里就能选到 `dsh-web-omni` 开始对话。不用另起服务，不用填地址，不用改配置文件。

## 安装

```sh
dsh plugin --profile <profile> add github:qq563778000-lgtm/dsh-web-omni
```

`<profile>` 是你的 DSH profile 名（桌面端通常是 `desktop`，Web 端是 `web`）。
安装后**重启 DSH**。

然后在模型选择器里选 `deepseek-flash`（来源：dsh-web-omni）开始对话。

**Token 不用手动填**：第一次对话时插件会自动从你本机浏览器读取 DeepSeek 的登录态，
验证通过就直接用上。只要你在浏览器里登录过 DeepSeek，就能直接开始聊。

想提前配置或管理多个账号，去设置页的 **dsh-web-omni** 一节。

## 设置页一览

设置页从上到下：

| 区域 | 作用 |
|---|---|
| 统计 | 可用 / 总数 / 已禁用三个计数 |
| 对话模式 / 会话亲和 | 两个开关并排，决定"发给上游什么"和"怎么省 token"，见下方 |
| 凭据列表 | 每行一条凭据，带状态图标、测试、删除 |
| 添加区 | 粘贴 Token，或点云图标从浏览器自动获取 |
| 如何获取 Token | 折叠区，含手动获取步骤 |
| 刷新 | 重新读取凭据池状态 |

### 凭据列表

每行显示掩码后的 Token（`abcdef...7890`），右侧三个图标：

| 图标 | 作用 |
|---|---|
| ✓ / ✗ / — | 状态：可用 / 失效 / 未测试 |
| 药丸 | 测试这一条是否还能用（只测这一条，不影响其它） |
| 垃圾桶 | 删除 |

鼠标悬停会显示对应说明。

### 添加区

| 元素 | 作用 |
|---|---|
| 输入框 | 粘贴 Token |
| ＋ | 添加 |
| ☁ | 从浏览器自动获取 |

## 从浏览器获取 Token

**不用先去设置页操作。** 装完直接开始对话就行 —— 第一次对话时如果发现还没有可用的
Token，插件会自动去本机浏览器把登录态读出来，验证通过就自动用上，你可以直接继续
聊下去。

想手动触发也可以：设置页点云图标，插件会读取本机浏览器的登录态，
**自动把还能用的都加进列表**。

- 扫本机所有浏览器、所有账号配置（Chrome 的多个 Profile、Edge 等），多个账号
  都登录过也不会漏
- 每一条都会先验证是否还有效，失效的不会写进列表
- 只读不改，不会动你的浏览器数据
- 自动获取只在**一个可用 Token 都没有**时才会触发；你已经配好了就完全不受影响

**一个前提**：Chrome 在页面打开时会把浏览器里的数据留在内存里、还没写到磁盘。
所以如果刚登录完就读不到 —— **把 chat.deepseek.com 那个标签页关掉（Ctrl+W）**
再试一次即可。不必重启浏览器，登录态也不会丢。

自动获取失败时，插件会告诉你具体原因和该做什么：是没登录、是数据还没落盘，
还是读到的是过期记录 —— 这三种的处置方式不同，不用自己猜。

### 浏览器退出登录了怎么办

**在浏览器里退出 DeepSeek 登录，会让已获取的 Token 立刻失效** —— 这是上游的服务端
行为，不是本地文件被改。所以退出登录后对话会失败。

处理办法：**在浏览器里重新登录，然后点设置页的云图标**（或直接再发一条消息）。
插件会重新扫描浏览器、拿到新的 Token，并把已经失效的那些从列表里清掉。

- 失效的 Token 会被自动删除，列表里不会留一堆失效项
- 重新获取不需要重启 DSH
- 自动获取在没东西可用时会自己触发；点云图标则立刻执行，不用等

### 用账号密码登录

设置页展开「用账号密码登录」，填 DeepSeek 的邮箱和密码，点「登录并添加」。

它会在后台打开一个浏览器完成登录，再把登录态存成 Token —— 因此：

- **密码不会被保存**，只用于这一次登录；存下来的只有 Token
- 需要本机装有 Chrome 或 Edge（登录页有防机器人校验，必须用真实浏览器）
- 大约 20 秒，比点云图标慢

什么时候用它：浏览器里没登录 DeepSeek，又不想手动复制 Token 时。
已经登录过浏览器的话，点云图标更快。

### 手动获取

设置页的「如何获取 Token」里有完整步骤：

1. 浏览器打开 `chat.deepseek.com` 并登录
2. 按 F12 → Console
3. 粘贴设置页给出的那段命令并回车，Token 会自动进剪贴板

命令找不到时用最通用的办法：F12 → Network → 任选一个 `api` 请求 → 复制
`Authorization` 头里 `Bearer ` 之后的部分。

Token 等同于账号登录态，只保存在本机，不要分享。

## 对话模式

设置页第一个开关，决定发给上游的内容。切换即时生效，不用重启。

| 模式 | 效果 |
|---|---|
| **Ask**（默认） | **原生对话**。只发送你说的话，不带任何系统设定与工具声明，模型就是 DeepSeek 本来的样子 |
| **Agent** | 完整能力。模型知道自己是个编码助手，可以读写文件、执行命令、跑多步任务 |

Ask 与"只是不给工具"不同：它连 DSH 平时附加的内容都不发，模型不知道自己
是编码助手。实测同一句「你是谁？」：

- Ask → "我是 DeepSeek，由深度求索公司创造的 AI 助手。"
- Agent → "我是你的编程助手，可以帮你读代码、查文件、改代码……"

默认是 Ask：装完直接就能问答，不带一堆用不上的东西。想让模型动手改代码时
再切到 Agent，切换即时生效。

你手动切换过的选择会被记住，之后升级插件不会把它改回去。

## 会话亲和

设置页第二个开关。

| 状态 | 效果 |
|---|---|
| **开**（默认） | 同一段对话复用上游会话，只发新增的部分。长对话明显更省、更快 |
| **关** | 每轮都重发完整历史。最兼容，但输入成本更高 |

长对话建议保持开启。

## 思考模式

模型选择器旁的思考档位只有两档：**关闭思考** 与 **深度思考**。

上游只支持开关思考，没有更细的强度分级 —— 所以这里也只给两档，
不做看起来能选、实际没区别的假选项。

## 数据与安全

- Token 只存在本机，不上传到任何地方
- 设置页与接口响应只返回掩码，没有"查看明文"的入口
- 不读取、不改动你浏览器的任何数据

## 使用须知

本插件使用 DeepSeek **Web 端**接口，不是官方 API。发布前请了解：

- **上游的接口、风控与限额随时可能变化**，插件可能因此失效。这不是本插件能
  保证的部分。
- **自动化调用 Web 端可能违反上游服务条款**，存在账号被限流或封禁的可能。
  请自行评估，风险自负。
- 不要把 Token 分享给他人；不要把本插件部署成对外提供的公共服务
  （那会把你的账号暴露给不受控的使用量）。

需要 SLA 保障、可商用授权的调用方式，请使用 DeepSeek 官方 API。

## 常见问题

**模型选择器里看不到 dsh-web-omni**
安装后要重启 DSH。凭据为空时插件不会产生任何上游请求，但模型来源仍会显示。

**第一次对话提示"没有找到 DeepSeek 的登录态"**
插件会自动去浏览器读登录态，但没读到。按提示处理：

- 提示"数据还没落盘" → 把 chat.deepseek.com 的标签页关掉（Ctrl+W）再发一次
- 提示"读到的是已失效的登录记录" → 重新登录 DeepSeek，关掉标签页后再试
- 提示"没有找到登录态" → 浏览器里确实没登录过，先去 chat.deepseek.com 登录

失败后不会立刻重试（避免每条消息都白等几秒），但过几分钟会自动再试；
想立刻重试，点设置页的云图标即可。

**对话突然失败，提示 Token 失效**
多半是你在浏览器里退出了 DeepSeek 登录 —— 退出会让已获取的 Token 立刻失效。
在浏览器里重新登录，然后点云图标（或直接再发一条消息）就能恢复，
不用重启 DSH。

**云图标点了没反应 / 提示数据没落盘**
把 chat.deepseek.com 的标签页关掉（Ctrl+W）再点。若仍不行，看浏览器里是否
真的登录过 DeepSeek。

**凭据显示失效（✗）**
上游判定该 Token 已过期。重新登录 DeepSeek、关掉标签页让数据落盘，再点一次
云图标即可。

**对话报"消息发送过于频繁"**
上游限流。稍等片刻重试；插件也会自动退避重试几次。

## 兼容性与已知限制

- 已验证的 DSH 版本：`0.2.1-rc.2`、`rc.3`；更高版本需实机确认
- 图片支持 URL 与 base64
- 对话特别长时插件会自动精简早期内容并接续，不至于中途卡住
- 首次对话若需自动获取凭据，会多花几秒（要读取浏览器数据并验证）
